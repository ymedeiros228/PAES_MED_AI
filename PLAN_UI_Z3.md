## Princípios de informação

1. **Um job por tela**  
   - Hoje = começar  
   - Fila = próximo item  
   - Sessão = responder  
   - Domínio = escolher tópico  
   - Plano = marcar dias  
   - Biblioteca = acervo  
   - Ajustes = preferências + avançado colapsado  

2. **Hierarquia**  
   - L1: título + 1 CTA  
   - L2: até 3 seções acionáveis  
   - L3: stats suaves  
   - L∞: `ExpansionTile` / “Avançado”  

3. **Vocabulário aluno**  
   | Em vez de | Use |
   |-----------|-----|
   | Base oficial / TREINO | “Com provas UEMA” / “Ainda no treino” |
   | Draft / real / template | esconder (só Aceitar / Revisar) |
   | Cross-domain / classify | Avançado |
   | API offline | “Conexão local off — reabra o app” |
   | preferNatureza | não mostrar |

4. **Foco default** — nav enxuta; Analytics/ferramentas não invadem o fluxo.
